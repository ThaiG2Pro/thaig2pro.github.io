# Trạng thái dây chuyền content

`state.json` là nguồn sự thật duy nhất cho tiến độ nhiều tuần. **Đừng sửa tay** — dùng
các skill `/content-*` để nó luôn nhất quán với `history` và `log`.

File này được git track có chủ đích: mất máy vẫn còn tiến độ, và lịch sử commit cho
thấy nhịp làm việc thật. Đổi lại, repo này công khai — nên **không ghi vào đây** thông
tin nhạy cảm (tên công ty, tên đồng nghiệp, số liệu nội bộ). Những thứ đó thuộc về
`career/` và `drafts/`, cả hai đều gitignore.

Xem nhanh: `/content-status`.
